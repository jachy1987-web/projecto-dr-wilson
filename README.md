# Doctor Wilson - Sistema de Gestión Veterinaria (Módulo Front-end)

Sistema web desarrollado para la administración y control de una clínica veterinaria, permitiendo gestionar de forma sencilla la información de propietarios, mascotas, citas, historias clínicas y personal administrativo.

- JavaScript (ES6+ / Fetch API)
- Control de versiones con Git y GitHub
